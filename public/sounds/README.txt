# サウンド差し替えガイド

## フォルダ構成

| フォルダ | 用途 | ファイル例 |
|---------|------|-----------|
| `voice/` | 衝突リアクション | `scream_s1〜3.wav`（小） / `scream_b1〜3.wav`（大） |
| `pick/` | 本ピッキング | `paper-01.wav` … |
| `footstep/` | 走行足音 | `step-01.wav` … |
| `crash/` | 体当たりインパクト | `impact-01.wav` … |

## 悲鳴カテゴリ

| カテゴリ | manifest キー | 再生タイミング |
|---------|---------------|----------------|
| **Scream_Small（小）** | `voice.screamSmall` | 軽い接触・譲り合い（yield） |
| **Scream_Big（大）** | `voice.screamBig` | 強ノックバック・吹き飛び |

各プールから **ランダムに1つ** 再生されます。ファイル追加時は `src/game/audio/manifest.ts` の配列にパスを追記してください。

## コンボ音

デフォルトは Web Audio 合成（コンボ数に応じて音階上昇）。
サンプルを使う場合は `manifest.ts` の `combo.chime` にパスを追加します。

## クールダウン（AudioManager 内蔵）

| カテゴリ | 間隔目安 |
|---------|---------|
| 足音 | 80ms |
| ピック | 120ms |
| インパクト | 150ms |
| 小悲鳴 | 180ms |
| 大悲鳴 | 280ms |
| コンボ | 100ms |

同時悲鳴は最大 **2** まで。

## プレースホルダー再生成

```bash
node scripts/generate-sounds.mjs
```

## 音量

ゲーム内「サウンド設定」で **コンボ** / 悲鳴 / 足音 等を個別調整できます。
